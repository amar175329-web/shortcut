# Shortcut ⚡ (CapCut Redesigned)

> Next-Generation, Privacy-First, Zero-Bloat Web Video Editor.

## 🌟 Highlights
- **Zero Watermarks, Zero Paywalls**: Full access to 4K 60FPS export without artificial tier locks.
- **Magnetic Multi-Track Timeline**: High-precision trimming, snapping, razor splitting (`C`), and ripple editing.
- **Creator Safe-Zone Guides**: Live TikTok and Instagram Reels overlay simulators.
- **Viral Subtitle Presets**: Hormozi Punch, Karaoke Glow, and Minimalist typography rendered directly on Canvas.
- **Color LUTs & Grading**: Real-time exposure, contrast, temperature, and blend modes.
- **Local Client-Side AI**: Auto-captions, silence gap removal, and noise reduction.

## 🚀 Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

The application runs on `http://localhost:3000/`.
